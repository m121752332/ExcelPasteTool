이 도구로 할 수 있는 일

Excel에 품번, 전표 번호, 코드 등이 한 열로 있고, 이를 ERP 조회나 SQL의 WHERE ... IN에 쓰고 싶다고 합시다. 구분 기호와 따옴표를 하나씩 직접 붙이면 시간이 걸리고 실수하기 쉽습니다. 이 도구는 열 전체를 한 번에 변환해 줍니다.

3단계로 시작하기

  1. Excel에서 한 열 복사

    변환할 셀(한 열, 행 수는 자유)을 선택하고 Ctrl + C를 누릅니다.

  2. 이곳으로 돌아와 「데이터 붙여넣기」 클릭

    도구 페이지에서 오른쪽 위의 데이터 붙여넣기를 누릅니다. 각 값이 오른쪽 표에 한 행씩 나타납니다. 빈 줄과 중복된 값은 자동으로 제외됩니다.

  3. 필요한 결과 복사

    왼쪽에 「PIP 구분 데이터」와 「SQL 조건」이 동시에 만들어집니다. 각 제목 오른쪽의 복사 버튼 ⧉을 누른 뒤, ERP나 SQL 도구에서 Ctrl + V로 붙여넣으세요.

참고텍스트 상자에서 Ctrl + V를 누르지 말고 「데이터 붙여넣기」 버튼을 사용하세요. 버튼은 Excel의 각 행을 한 건씩 나눠 줍니다. 텍스트 상자에 붙여넣으면 전체가 하나의 문자열로 처리됩니다.

더 알아보기

하고 싶은 일방법
다른 구분 기호 사용위쪽 도구 모음의 「구분 기호」 목록에서 선택합니다. 이미 붙여넣은 데이터는 새 기호로 즉시 다시 연결됩니다.
일부 값 제외데이터 표의 행 위에 마우스를 올리고 오른쪽의 ✕를 클릭합니다.
직접 추가·수정「PIP 구분 데이터」 칸에 직접 입력합니다. 값 사이는 현재 구분 기호로 구분하세요. 예: A-001|A-002
열을 Excel로 다시 복사표 왼쪽 위의 「행 번호」 머리글을 클릭합니다. 모든 값이 한 줄에 하나씩 복사되어 Excel에 그대로 붙여넣을 수 있습니다.
처음부터 다시 시작「데이터 지우기」를 클릭합니다.
패널 너비 조절왼쪽과 오른쪽 패널 사이의 경계를 드래그합니다.

자주 묻는 질문

「데이터 붙여넣기」를 눌렀는데 아무 일도 일어나지 않습니다.

클립보드에 텍스트가 없습니다. Excel로 돌아가 셀을 선택하고 Ctrl + C를 누른 다음 버튼을 다시 클릭하세요.

여러 열을 복사했는데 왜 첫 번째 열만 나오나요?

의도된 동작입니다. 각 행의 첫 번째 열만 사용합니다. 다른 열이 필요하면 Excel에서 그 열만 선택해 복사하세요.

Excel보다 건수가 적은 이유는 무엇인가요?

빈 행과 중복된 값이 제외되므로, 건수는 중복을 제거한 값의 개수입니다.

값의 일부가 잘렸습니다.

붙여넣을 때 한 행 안에 Tab, 쉼표 ,, 세미콜론 ;, 세로선 |이 있으면 열 구분으로 간주해 첫 번째 부분만 남깁니다. 예를 들어 A-001,red는 A-001이 됩니다. 값 자체에 이런 기호가 들어 있다면 「PIP 구분 데이터」 칸에 직접 입력하세요. 구분 기호가 쉼표일 때는 "A-001,red"처럼 큰따옴표로 감싼 값은 나뉘지 않고 그대로 유지됩니다.

값에 작은따옴표가 있으면 SQL이 깨지나요?

아니요. 작은따옴표는 자동으로 두 개가 되어 O'Brien은 'O''Brien'으로 작성됩니다. SQL의 표준 방식입니다.

도구 모음에서 언어나 테마를 바꿨는데 다음에 열면 원래대로 돌아가 있습니다.

도구 모음의 변경은 현재 세션에만 적용됩니다. 유지하려면 왼쪽 메뉴의 「설정」 페이지에서 변경하세요.

설정은 어디에 저장되나요? 저장되지 않는 이유는 무엇인가요?

설정은 프로그램 옆의 config.json에 저장됩니다. 프로그램이 쓰기 권한이 없는 폴더(예: C:\Program Files)에 있으면 설정을 저장할 수 없습니다. 폴더 전체를 바탕 화면이나 문서 폴더로 옮기세요.

새 버전으로 업데이트하려면 어떻게 하나요?

프로그램은 시작할 때 새 버전을 확인합니다. 새 버전이 있으면 안내가 표시되며, 프로그램 안에서 바로 다운로드하여 업데이트할 수 있습니다.
