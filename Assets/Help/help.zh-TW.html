這個工具在做什麼

你在 Excel 有一欄料號、單號或代碼，想拿去 ERP 查詢，或寫進 SQL 的 WHERE ... IN。自己一個一個加分隔符號和引號很花時間，也容易漏。這個工具幫你一次轉好。

Excel 裡的一欄
A
A-001
A-002
B-105
C-330
→
分隔資料（貼到 ERP 或報表的多值查詢欄位）
A-001|A-002|B-105|C-330
SQL 條件（接在 WHERE 欄位 IN 後面）
('A-001', 'A-002', 'B-105', 'C-330')

三步驟快速上手

  1. 在 Excel 複製一欄資料

    用滑鼠選取要轉換的儲存格（同一欄，可以很多列），按 Ctrl + C 複製。

  2. 回到本程式，按「資料貼上」

    在左側選單的「工具」頁，按右上方的 資料貼上。資料會一筆一筆列在右邊的表格，空白行和重複的值會自動去掉。

  3. 複製你要的結果

    左邊會同時產生「PIP 分隔資料」和「SQL 條件」。按各自標題右邊的複製按鈕 ⧉，再到 ERP 或 SQL 工具按 Ctrl + V 貼上。

提醒請用「資料貼上」按鈕，不要直接在輸入框按 Ctrl + V。按鈕會把 Excel 的每一列拆成一筆；直接貼進輸入框則會被當成一整段文字。

更多操作

想做的事怎麼做
換一種分隔符號在上方工具列的「分隔符號」選單選擇。已貼上的資料會立刻用新符號重新串接。
拿掉其中幾筆滑鼠移到資料表的那一列，按右邊的 ✕。
手動加資料或修改直接在「PIP 分隔資料」框裡打字，每一筆之間用目前的分隔符號隔開，例如 A-001|A-002。
把整欄複製回 Excel按資料表左上角的「行號」表頭，會複製全部資料（一筆一行），可以直接貼回 Excel。
重新開始按「清空資料」。
調整左右寬度用滑鼠拖曳左右兩個面板中間的空隙。

常見問題

按了「資料貼上」卻沒有反應？

剪貼簿裡沒有文字。請先回 Excel 選取儲存格並按 Ctrl + C，再回來按一次。

我複製了好幾欄，為什麼只出現第一欄？

這是設計如此：每一列只取第一欄。如果你要的是其他欄，請在 Excel 只選那一欄再複製。

筆數比 Excel 的列數少？

空白列和重複的值會自動去掉，所以筆數是「不重複的資料」數量。

資料被切掉了一半？

貼上時，如果一列裡面有 Tab、逗號 ,、分號 ; 或豎線 |，程式會把它當成欄位分隔，只留下第一段。例如 A-001,紅色 會變成 A-001。資料本身含有這些符號時，請改在「PIP 分隔資料」框裡手動輸入。

資料裡有單引號，SQL 會不會壞掉？

不會。單引號會自動變成兩個單引號，例如 O'Brien 會輸出成 'O''Brien'，這是 SQL 的標準寫法。

我在工具列換了語言或主題，下次開啟又變回來？

工具列上的語言和主題只是暫時切換。要永久保存，請到左側選單的「設定」頁調整。

設定存在哪裡？為什麼沒有存起來？

設定存在程式旁邊的 config.json。如果程式放在不能寫入的資料夾（例如 C:\Program Files），設定就存不起來，請把整個資料夾搬到桌面或文件。

怎麼更新到新版本？

程式啟動時會自動檢查。有新版本時會跳出提示，按照畫面指示就能在程式內下載並更新。

快捷鍵與設定

按鍵功能
F1開啟這份說明（在任何頁面都可以按）。
工具頁右上角「導覽」重看操作導覽（第一次開啟程式時會自動播放一次）。導覽中可按 ← → 切換步驟、Space 前往下一步、Esc 略過。
Ctrl + C複製輸入框或資料表中選取的文字。

Alt + F4強制關閉程式（導覽進行中或有對話框時也會直接結束）。
