DataSplitter Pro ヘルプ

このツールでできること

Excel に品番・伝票番号・コードなどの列があり、それを ERP の検索や SQL の WHERE ... IN に使いたいとします。区切り文字や引用符を 1 つずつ手で付けるのは時間がかかり、間違いのもとです。このツールなら列全体を一度に変換できます。

Excel の 1 列
A
A-001
A-002
B-105
C-330
→
区切りデータ（ERP やレポートの複数値検索欄に貼り付け）
A-001|A-002|B-105|C-330
SQL 条件（WHERE 列名 IN の後ろに貼り付け）
('A-001', 'A-002', 'B-105', 'C-330')

3 ステップで始める

  1. Excel で 1 列をコピー

    変換したいセル（1 列、行数は自由）を選択して Ctrl + C を押します。

  2. ここに戻って「データ貼り付け」をクリック

    ツールページで、右上の データ貼り付け を押します。各データが右側の表に 1 行ずつ表示されます。空行と重複した値は自動的に除かれます。

  3. 必要な結果をコピー

    左側に「PIP 区切りデータ」と「SQL 条件」が同時に作成されます。それぞれのタイトルの右にあるコピーボタン ⧉ を押し、ERP や SQL ツールで Ctrl + V を押して貼り付けます。

ご注意テキストボックスで Ctrl + V を押すのではなく、「データ貼り付け」ボタンを使ってください。ボタンは Excel の各行を 1 件ずつに分けます。テキストボックスに貼り付けると全体が 1 つの文字列として扱われます。

よくある質問

「データ貼り付け」を押しても何も起きません。

クリップボードにテキストがありません。Excel に戻ってセルを選択し、Ctrl + C を押してから、もう一度ボタンを押してください。

複数列をコピーしたのに、なぜ先頭の列だけになるのですか？

仕様です。各行の先頭の列だけを使います。別の列が必要な場合は、Excel でその列だけを選択してコピーしてください。

Excel より件数が少ないのはなぜですか？

空行と重複した値が除かれるため、件数は重複を除いた値の数になります。

値の一部が切れてしまいました。

貼り付け時、行の中に Tab、カンマ ,、セミコロン ;、縦線 | があると列の区切りとみなされ、最初の部分だけが残ります。たとえば A-001,red は A-001 になります。値自体にこれらの記号が含まれる場合は、「PIP 区切りデータ」欄に直接入力してください。区切り文字がカンマのときは、"A-001,red" のように二重引用符で囲んだ値は分割されずそのまま扱われます。

値に単一引用符が含まれていても SQL は壊れませんか？

大丈夫です。単一引用符は自動的に 2 つになり、O'Brien は 'O''Brien' と書かれます。これは SQL の標準的な書き方です。

ツールバーで言語やテーマを変えたのに、次回は元に戻っていました。

ツールバーでの切り替えは現在のセッションだけに有効です。保存したい場合は、左メニューの「設定」ページで変更してください。

設定の保存先はどこですか？保存されないのはなぜですか？

設定はプログラムと同じ場所の config.json に保存されます。プログラムが書き込めないフォルダー（例：C:\Program Files）にある場合は設定を保存できません。フォルダーごとデスクトップやドキュメントに移動してください。

新しいバージョンに更新するには？

プログラムは起動時にバージョンを確認します。新しいバージョンがあるとお知らせが表示され、プログラム内からダウンロードして更新できます。
