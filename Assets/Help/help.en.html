What this tool does

You have a column of item numbers, order numbers or codes in Excel, and you want to use them in an ERP query or in a SQL WHERE ... IN. Adding separators and quotes by hand is slow and easy to get wrong. This tool converts the whole column at once.

Quick start in 3 steps

  1. Copy one column in Excel

    Select the cells you want to convert (one column, as many rows as you like) and press Ctrl + C.

  2. Come back here and click "Paste Data"

    On the Tools page, click Paste Data at the top right. Each value appears as a row in the table on the right. Blank lines and duplicate values are removed automatically.

  3. Copy the result you need

    "PIP Separated Data" and "SQL Condition" are filled in on the left at the same time. Click the copy button ⧉ next to either title, then press Ctrl + V in your ERP or SQL tool.

NoteUse the "Paste Data" button instead of pressing Ctrl + V in the text box. The button splits each Excel row into its own value. Pasting into the text box treats everything as one piece of text.

FAQ

I clicked "Paste Data" and nothing happened.

The clipboard has no text. Go back to Excel, select the cells, press Ctrl + C, then click the button again.

I copied several columns. Why do I only get the first one?

That is by design: only the first column of each row is used. If you need a different column, select only that column in Excel and copy it.

Why is the row count lower than in Excel?

Blank rows and duplicate values are removed, so the count is the number of unique values.

Part of my value was cut off.

When pasting, a Tab, comma ,, semicolon ; or pipe | inside a row is treated as a column separator, and only the first part is kept. For example A-001,red becomes A-001. If your values contain these characters, type them in the "PIP Separated Data" box instead.

My values contain single quotes. Will the SQL break?

No. A single quote is doubled automatically, so O'Brien is written as 'O''Brien', which is the standard SQL way.

I changed the language or theme in the toolbar, but it was back to the old one next time.

The toolbar only switches them for the current session. To keep the change, set it on the Settings page in the left menu.

Where are settings stored, and why were mine not saved?

Settings are stored in config.json next to the program. If the program is in a folder it cannot write to (for example C:\Program Files), settings cannot be saved. Move the whole folder to your Desktop or Documents.

How do I update to a new version?

The program checks at startup. When a new version is available it shows a prompt, and you can download and install the update from inside the program.
