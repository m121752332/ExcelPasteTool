这个工具在做什么

你在 Excel 有一列料号、单号或代码，想拿去 ERP 查询，或写进 SQL 的 WHERE ... IN。自己一个一个加分隔符号和引号很花时间，也容易漏。这个工具帮你一次转好。

Excel 里的一列
A
A-001
A-002
B-105
C-330
→
分隔数据（粘贴到 ERP 或报表的多值查询栏位）
A-001|A-002|B-105|C-330
SQL 条件（接在 WHERE 字段 IN 后面）
('A-001', 'A-002', 'B-105', 'C-330')

三步快速上手

  1. 在 Excel 复制一列数据

    用鼠标选取要转换的单元格（同一列，可以很多行），按 Ctrl + C 复制。

  2. 回到本程序，点「数据粘贴」

    在左侧菜单的「工具」页，点右上方的 数据粘贴。数据会一条一条列在右边的表格，空白行和重复的值会自动去掉。

  3. 复制你要的结果

    左边会同时产生「PIP 分隔数据」和「SQL 条件」。点各自标题右边的复制按钮 ⧉，再到 ERP 或 SQL 工具按 Ctrl + V 粘贴。

提醒请用「数据粘贴」按钮，不要直接在输入框按 Ctrl + V。按钮会把 Excel 的每一行拆成一条；直接粘贴进输入框则会被当成一整段文字。

更多操作

想做的事怎么做
换一种分隔符号在上方工具栏的「分隔符号」菜单选择。已粘贴的数据会立刻用新符号重新串接。
拿掉其中几条鼠标移到数据表的那一行，点右边的 ✕。

调整左右宽度用鼠标拖动左右两个面板中间的空隙。

常见问题

点了「数据粘贴」却没有反应？

剪贴板里没有文字。请先回 Excel 选取单元格并按 Ctrl + C，再回来点一次。

我复制了好几列，为什么只出现第一列？

这是设计如此：每一行只取第一列。如果你要的是其他列，请在 Excel 只选那一列再复制。

笔数比 Excel 的行数少？

空白行和重复的值会自动去掉，所以笔数是「不重复的数据」数量。

数据被切掉了一半？

粘贴时，如果一行里面有 Tab、逗号 ,、分号 ; 或竖线 |，程序会把它当成列分隔，只留下第一段。例如 A-001,红色 会变成 A-001。数据本身含有这些符号时，请改在「PIP 分隔数据」框里手动输入。

数据里有单引号，SQL 会不会坏掉？

不会。单引号会自动变成两个单引号，例如 O'Brien 会输出成 'O''Brien'，这是 SQL 的标准写法。

我在工具栏换了语言或主题，下次打开又变回来？

工具栏上的语言和主题只是临时切换。要永久保存，请到左侧菜单的「设定」页调整。

设定存在哪里？为什么没有保存？

设定存在程序旁边的 config.json。如果程序放在不能写入的文件夹（例如 C:\Program Files），设定就存不了，请把整个文件夹搬到桌面或文档。

怎么更新到新版本？

程序启动时会自动检查。有新版本时会弹出提示，按照界面指示就能在程序内下载并更新。

快捷键与设定

按键功能
F1打开这份说明（在任何页面都可以按）。
工具页右上角「导览」重看操作导览（第一次打开程序时会自动播放一次）。导览中可按 ← → 切换步骤、Esc 跳过。
Ctrl + C复制输入框或数据表中选取的文字。

Alt + F4强制关闭程序（导览进行中或有对话框时也会直接结束）。
