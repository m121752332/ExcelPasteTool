这个工具在做什么

你在 Excel 有一列料号、单号或代码，想拿去 ERP 查询，或写进 SQL 的 WHERE ... IN。自己一个一个加分隔符号和引号很花时间，也容易漏。这个工具帮你一次转好。

Excel 里的一列
A
A-001
A-002
B-105
C-330
→
分隔数据（粘贴到 ERP 或报表的多值查询栏位）
A-001|A-002|B-105|C-330
SQL 条件（接在 WHERE 字段 IN 后面）
('A-001', 'A-002', 'B-105', 'C-330')

三步快速上手

  1. 在 Excel 复制一列数据

    用鼠标选取要转换的单元格（同一列，可以很多行），按 Ctrl + C 复制。

  2. 回到本程序，点「数据粘贴」

    在左侧菜单的「工具」页，点右上方的 数据粘贴。数据会一条一条列在右边的表格，空白行和重复的值会自动去掉。

  3. 复制你要的结果

    左边会同时产生「PIP 分隔数据」和「SQL 条件」。点各自标题右边的复制按钮 ⧉，再到 ERP 或 SQL 工具按 Ctrl + V 粘贴。

提醒请用「数据粘贴」按钮，不要直接在输入框按 Ctrl + V。按钮会把 Excel 的每一行拆成一条；直接粘贴进输入框则会被当成一整段文字。

更多操作

想做的事怎么做
换一种分隔符号在上方工具栏的「分隔符号」菜单选择。已粘贴的数据会立刻用新符号重新串接。
拿掉其中几条鼠标移到数据表的那一行，点右边的 ✕。
手动加数据或修改直接在「PIP 分隔数据」框里打字，每一条之间用当前的分隔符号隔开，例如 A-001|A-002。
补数据，不要覆盖点「数据粘贴」旁的「追加粘贴」或 Alt + Shift + P，剪贴板内容会接在现有数据后面，已经有的值自动跳过。也可以点表格最下面的「＋ 新增一条」手动输入（按 Enter 确认后会接着开下一条），或点一下某一行再按 Insert，在它下面插入一条。
修改某一条在数据表双击那一条就能直接修改，Enter 或点别处确认、Esc 取消。改成和别条一样的值不会生效；清空就等于删除。左边的分隔数据和 SQL 会一起更新。
不需要 SQL 条件点「SQL 条件」标题右边的眼睛按钮 👁 就会收起，上方的分隔数据框会撑满；再点一次打开。想每次打开 App 都先收起，到「设置 › 一般设置」关掉「显示 SQL 条件区块」。
SQL 加上字段名称或改格式点「SQL 条件」标题右边的格式选项按钮 ☰，可以填「字段名称」（例如 ima01，会输出 ima01 IN (...)）、勾选「数值不加引号」（全部都是数字才生效，有前导零的料号如 001 仍会加引号），以及设置「每行笔数」（括号内每 N 笔换一行，0 表示不换行，方便粘贴进 4GL 或 SQL*Plus）。设置会记住，下次打开沿用。
把整列复制回 Excel点数据表左上角的「行号」表头，会复制全部数据（一条一行），可以直接粘贴回 Excel。
重新开始点「清空数据」。
调整左右宽度用鼠标拖动左右两个面板中间的空隙。
调整上下高度拖动「PIP 分隔数据」与「SQL 条件」中间的分隔条（有三个小点），位置会记住。

常见问题

点了「数据粘贴」却没有反应？

剪贴板里没有文字。请先回 Excel 选取单元格并按 Ctrl + C，再回来点一次。

我复制了好几列，为什么只出现第一列？

这是设计如此：每一行只取第一列。如果你要的是其他列，请在 Excel 只选那一列再复制。

笔数比 Excel 的行数少？

空白行和重复的值会自动去掉，所以笔数是「不重复的数据」数量。

数据被切掉了一半？

粘贴时，如果一行里面有 Tab、逗号 ,、分号 ; 或竖线 |，程序会把它当成列分隔，只留下第一段。例如 A-001,红色 会变成 A-001。数据本身含有这些符号时，请改在「PIP 分隔数据」框里手动输入。

数据里有单引号，SQL 会不会坏掉？

不会。单引号会自动变成两个单引号，例如 O'Brien 会输出成 'O''Brien'，这是 SQL 的标准写法。

超过 1000 笔，Oracle 出现 ORA-01795？

Oracle 的单一 IN 列表最多 1000 个值。超过 1000 笔时，程序会自动每 1000 笔拆成一组，用 OR 连接，例如 (ima01 IN (...) OR ima01 IN (...))，外面再包一层括号，接在其他 AND 条件后面也不会出错。没有填字段名称时暂用 col，SQL 条件下方会有黄色提醒，请到格式选项填入或粘贴后自行替换。

我在工具栏换了语言或主题，下次打开又变回来？

工具栏上的语言和主题只是临时切换。要永久保存，请到左侧菜单的「设定」页调整。

设定存在哪里？为什么没有保存？

设定存在程序旁边的 config.json。如果程序放在不能写入的文件夹（例如 C:\Program Files），设定就存不了，请把整个文件夹搬到桌面或文档。

怎么更新到新版本？

程序启动时会自动检查。有新版本时会弹出提示，按照界面指示就能在程序内下载并更新。也可以到「设定 › 更新设置」按「检查更新」手动检查。
